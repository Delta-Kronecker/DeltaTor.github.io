Install the APK

First time only: Android asks permission to install from your browser or file manager.

Press the round button

Transports race automatically until one reaches 100%, and the winner stays connected.

What you get

Transport auto-race

vanilla, obfs4 and webtunnel start side by side — whichever bootstraps first wins, and a memory of past successes reconnects faster next time.

Bridges built in

Tested bridge lists ship inside every build and refresh from the collector, so a fresh install works before the first download.

Exit country control · Android

Pin any number of exit countries and see your real exit IP and country after connecting.

Zero telemetry

No account, no analytics, no crash reporting — the app never identifies you or phones home.
